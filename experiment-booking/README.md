# 2026 아인슈타인 동아리 방과후 실험 신청 앱

대표학생이 **학번(5자리)과 이름**을 입력한 뒤, 날짜별로 실험 신청서를 제출하는 앱입니다. 기존 동아리 활동 기록 앱과 별도의 Google Apps Script 프로젝트 및 Google 스프레드시트를 사용합니다.

## 신청 가능 날짜 / 마감

| 실험 날짜 | 마감 |
|---|---|
| 2026-11-02(월) 방과후 | 11-01 23:59 |
| 2026-11-04(수) 방과후 | 11-03 23:59 |
| 2026-11-05(목) 방과후 | 11-04 23:59 |
| 2026-11-06(금) 방과후 | 11-05 23:59 |
| 2026-11-09(월) 방과후 | 11-08 23:59 |
| 2026-11-10(화) 방과후 | 11-09 23:59 |

전날 23:59:59까지 제출할 수 있으며 실험 당일 00:00:00부터 서버에서 차단합니다(Asia/Seoul 기준). 교사는 날짜별 신청을 수동 차단할 수 있습니다.

## 학생 신청 순서

1. 대표학생 학번·이름 입력 (별도 비밀번호·개별코드 없음)
2. 실험 날짜 선택 (위 6일만 가능)
3. 참석 학생 명단 추가 (학번·이름, 행 추가)
4. 실험 주제·목적·방법·안전 유의사항
5. 구입할 준비물 추가 (품목명·종류/규격·수량·단가·G마켓 링크, 행 추가)
6. 과학실에 구비된 준비물 추가 (품목명·종류/규격·수량, 행 추가)
7. 최종 제출

날짜별 대표 학번당 신청서는 1건으로 제한됩니다. 다른 날짜에는 별도로 신청할 수 있습니다. 학번과 이름은 본인 인증이 되지 않으므로 **학생이 다른 신청서를 조회하거나 수정하는 기능은 제공하지 않습니다.** 제출 후 수정 요청은 교사에게 문의해야 합니다.

## 교사용 기능

- 날짜별 신청서 조회, 실험 계획서 및 참석 명단 확인
- 구입 준비물별 구매 필요 / 주문 완료 / 구입 완료 상태 관리
- 신청서 승인/수정 요청/반려, 교사 메모
- 신청일별 허용·차단, 안내사항 변경
- 신청 현황 및 준비물 CSV 다운로드 (개인정보 주의)

## Google Apps Script 설치 및 배포

**GitHub에 소스가 올라왔다고 학생 제출이 자동으로 작동하는 것은 아닙니다.** 이 앱은 Google Apps Script의 `google.script.run`과 Google 스프레드시트를 사용합니다. GitHub Pages에서 `Index.html`을 직접 열면 저장·조회 기능이 동작하지 않습니다.

1. 교사 구글 계정으로 [Google Apps Script](https://script.google.com/)에서 **새 프로젝트**를 생성합니다.
2. 기본 `코드.gs` 내용을 이 폴더의 [Code.gs](./Code.gs)로 교체합니다.
3. `ADMIN_SETUP_PASSWORD`를 **교사용으로 사용할 12자 이상의 비밀 암호**로 변경합니다. **설정한 실제 암호를 공개 GitHub 저장소에 커밋하지 마세요.** 이 값은 Apps Script 프로젝트에서만 편집합니다.
4. HTML 파일을 새로 추가하고 이름을 **Index**로 설정합니다. 내용은 [Index.html](./Index.html)을 그대로 붙여 넣습니다.
5. 프로젝트 설정의 시간대를 **Asia/Seoul**로 설정합니다.
6. 함수 목록에서 `setupApp`을 선택해 **한 번 실행**하고 Google 접근 권한을 승인합니다. 실행 로그에 관리 스프레드시트 주소가 출력됩니다.
7. **배포 → 새 배포 → 웹 앱**을 선택합니다. 실행 사용자 **나**, 액세스 권한은 학교 정책에서 허용하는 학생 접속 범위를 선택합니다.
8. 배포로 생성된 `/exec` 주소가 **학생용 신청 링크**입니다. 교사용 화면은 같은 주소 끝에 `?page=teacher`를 붙여 엽니다.
9. 실제 운영 전에 **학생용 테스트 신청 1건 → 교사용 조회 → 스프레드시트 반영 → 마감 후 차단** 순서로 점검합니다.

### 파일 구성

- `Index.html`: 학생용/교사용 반응형 화면 (GAS HTML 파일 이름은 Index)
- `Code.gs`: 신청 검증, 시트 저장, 마감 및 교사용 관리
- `README.md`: 설치·운영 안내

### 개인정보·권한 주의

- 관리 스프레드시트에는 학생 학번·이름과 실험 신청 내용이 포함됩니다. **시트를 공개 공유하지 마세요.**
- 학번·이름 입력만으로는 신원이 확인되지 않습니다. 학생에게 다른 사람의 신청내역을 노출하거나 수정 권한을 열지 않습니다.
- 배포 전 교사용 비밀번호를 반드시 교체하고, 학교 개인정보·접근 정책을 확인하세요.
- 기존 `einstein-club/index.html` 및 `poster/`는 변경하지 않습니다.
